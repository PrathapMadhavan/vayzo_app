HTTP Status Codes
API Standard
200 → Success
201 → Created
400 → Validation Error
401 → Unauthorized
403 → Forbidden
404 → Resource Not Found
409 → Conflict
422 → Business Validation Error
500 → Internal Server Error

==========================================================================================

Partner Request Status Flow
Core Delivery Workflow
REQUEST_RECEIVED
      ↓
ACCEPTED
      ↓
NAVIGATING_TO_PICKUP
      ↓
ARRIVED_AT_PICKUP
      ↓
ITEMS_PURCHASED / ORDER_PICKED_UP
      ↓
BILL_UPLOADED (Buy & Get only)
      ↓
NAVIGATING_TO_DROP
      ↓
ARRIVED_AT_DROP
      ↓
DELIVERY_OTP_VERIFIED
      ↓
COMPLETED

==========================================================================================

Partner Availability Rules
Online / Offline
OFFLINE → Partner does not receive new requests.
ONLINE → Partner can receive new requests.
BUSY → Partner is handling an active request.
SUSPENDED → Partner cannot go online.
UNDER_REVIEW → Registration is pending verification.
